# DA CALLER APK for direct installation

Version **0.10.0-beta.1**, versionCode **10**, package `com.dacaller.app`, Android 8.0/API26 or later (including Android13).

This is the exact locally built and signature-verified debug test candidate recorded in [the APK verification evidence](../docs/evidence/2026-10-24/local-apk-verification.json). The source passed 79 automated JVM tests; five Android13 UI tests passed in CI. It is a beta test build, not a field-verified production release. Real calls, ringing, audio, lock screen and Unihertz Jelly Star hardware behavior still require physical-device testing.

Download the `.apk` file directly and open it on Android. Android may ask you to allow installation from the browser or file manager. No ZIP extraction is needed.

**Existing v0.9.0 installations use a different signing certificate and cannot be updated in place with this APK. Do not uninstall an existing installation before preserving its private archive/settings; uninstall removes app data.** No existing tag/release is replaced.
